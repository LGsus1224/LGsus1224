<h2>👨‍💻 | About me</h2> 
🌐 I'm a Software Engineer with over 3 years of experience building robust, scalable, and user-centric solutions across the web ecosystem. My technical stack includes Python, Laravel, FastAPI, JavaScript, React, Django, Flask, MySQL, Firebase, and CodeIgniter. I specialize in software architecture, RESTful APIs, DevOps practices, and full-cycle web development.

🚀 I've led and contributed to impactful projects such as a SaaS-based e-invoicing API, a tournament management system for Karate Dojos, and a financial collection platform. My approach emphasizes clean, maintainable code and intuitive design focused on real-world usability.

💡 Passionate about solving real problems through technology, I thrive in collaborative environments where innovation, learning, and positive user impact are at the core. I’m fluent in Spanish and proficient in English, and I’m open to remote or hybrid opportunities, as well as consulting for custom software solutions.
